# ADR 0013: 계약 4.0.0의 기기 허용 목록과 사용자 ID

상태: 채택 (2026-11-07).

기기 토큰 생성·인증을 제거하고 Caddy의 검증된 인증서 CN·serial을 비공개 Unix 소켓 확인기로 전달한다. 확인기는 DeviceAllowlist를 매 요청 다시 읽고 검증한다. 같은 TLS 연결에서도 회전·폐기가 적용되고, 파일 오류·중복 기기는 503으로 닫히며 정상 파일로 복구되면 회복한다. 원자적 교체가 보이도록 파일의 부모 디렉터리를 마운트한다. Caddy 내부 인증 요청에는 외부 쿼리를 넘기지 않는다.

인증 전후 상태와 상류 호출은 route 안에서 순서를 고정한다. 인증 확인 장애는 503이고 상류 연결·시간 초과와 구분한다. 설정의 환경 이름은 PublicIngressEnv를 따른다.

HumanUserId 정본을 Keycloak 사용자 프로필과 입구의 인증된 신원 검사에 적용한다. 사용자 등록 잡은 전체 IdentityUsersConfig를 부작용 전에 검증한다. Go 검증기는 소유자 SDK처럼 패키지의 파일 URI와 원래 ID를 등록하며 외부 미설치 참조는 거부한다. 백업 결과는 표준 JSON 인코더와 BackupJobResult로 송신 전 검증한다.

정상·변이 mTLS/장애/인증 시험, 실제 Keycloak 등록·가입·로그인·출구 격리, 이미지 입력·영역 전체 시험으로 확인한다. 전체 프로젝트 E2E는 별도 최종 단계다.
